### ⚡ Nexorium Pulse

**Nexorium Pulse** is a lightweight multithreaded **TCP port scanner built in Python** for network reconnaissance in authorized environments.

I built this project while learning Python networking, socket programming, concurrency, Git, GitHub, and Linux-based security workflows.

<p align="center">
  <img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=14&pause=1500&color=38BDF8&center=false&vCenter=true&multiline=true&repeat=true&width=600&height=90&lines=%24+python+nexorium_pulse.py+--target+192.168.1.0%2F24;%5B%2B%5D+Scanning+65535+ports+with+100+threads...;%5B%2B%5D+Open%3A+22%2C80%2C443+%7C+Closed%3A+65532+%7C+Done+in+4.2s" alt="Nexorium Pulse terminal animation">

<tr><td valign="top">

**Scanning**
- ⚡ Multithreaded TCP scanning with up to 100 workers
- 🎯 Custom port range scanning (`1–65535`)
- 🔎 Open and closed port detection
- 🌐 TCP service lookup

</td><td valign="top">

**Reporting & Reliability**
- 📊 Scan statistics and execution time
- 📄 TXT report generation
- 📦 JSON report generation
